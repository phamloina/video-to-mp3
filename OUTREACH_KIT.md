## English tester post

> I maintain Video To MP3, an open-source Windows desktop app built with C#, .NET 8, WPF, FFmpeg, ffprobe, and yt-dlp. The first public preview supports queued local-file and supported-URL conversion, progress, retry/cancel, metadata, optional cover art, playlists, settings, and history.
>
> `v0.2.0-preview.1` is a no-admin Windows x64 portable release. FFmpeg, ffprobe, and yt-dlp remain explicit external dependencies under the documented `tools` directories.
>
> I am looking for Windows 10/11 testers who can report reproducible results for local MP4, supported URLs, cancellation/retry, and persistence after restart.

## Before posting

- Confirm the community permits project sharing or feedback requests.
- Use the language and level of detail appropriate for that community.
- State that you are the maintainer.
- Link to the release or UAT issue, not a tracking redirect.
- Mention external dependencies and pre-release status.
- Ask for reproducible feedback, not stars.
- Answer replies and close the loop on reported defects.
