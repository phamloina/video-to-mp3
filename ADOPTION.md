# Adoption Plan

The goal is to earn real usage through a useful release, transparent testing, and helpful contributor work. Stars, downloads, issues, and testimonials must come from genuine users.

## Current call to action

Test [`v0.2.0-preview.1`](https://github.com/phamloina/video-to-mp3/releases/tag/v0.2.0-preview.1) on Windows 10 or 11 and post the result in [UAT issue #28](https://github.com/phamloina/video-to-mp3/issues/28).

Useful feedback includes:

- Windows version and architecture
- Whether checksum verification passed
- Local-file or supported-URL workflow tested
- Expected and actual behavior
- Minimal reproduction steps and redacted logs

## Contributor path

1. Choose an open issue labeled `good first issue` or `help wanted`.
2. Comment before coding so work is not duplicated.
3. Follow [CONTRIBUTING.md](CONTRIBUTING.md).
4. Submit one focused pull request with tests and validation evidence.

## Ethical outreach

Maintainers may share the release in relevant Windows, .NET, WPF, FFmpeg, and open-source communities when self-promotion is allowed. Each post should disclose the maintainer relationship, link directly to the release or UAT issue, and ask for technical feedback rather than stars.

Do not:

- buy or exchange stars, downloads, reviews, or follows
- create fake accounts, issues, testimonials, or usage statistics
- mass-message unrelated users or communities
- hide external-tool requirements or pre-release limitations
- upload or encourage conversion of copyrighted content without permission

## Evidence to record

Record only public, verifiable evidence:

- GitHub release downloads
- unique external UAT comments
- reproducible bug reports
- outside pull requests or review comments
- repository stars and forks
- public mentions that follow community rules

Review the evidence before stable release planning and before using adoption claims in any application or project profile.
